# Error to source

```sh
SRC=$(ctx path <dep>-<ver>-src)
rg -n -F '<exact error text>' "$SRC"
```

Read the throw site and its guard conditions, then map them to actual local inputs.
Trace wrappers if the message is generated indirectly. Verify the fix at the real runtime boundary.
Cite file:line @ SHA; missing evidence is unknown, not a reason to guess.
